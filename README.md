# Paradise Nursery Shopping Application

Paradise Nursery is a responsive React and Redux shopping cart application for an online houseplant store. Customers can browse plants by category, add plants to a cart, adjust quantities, remove products, and see item counts and prices update instantly.

## Features

- Landing page with Paradise Nursery company information and a **Get Started** button
- Eighteen unique houseplants organized into three categories, with six plants in each category
- Plant cards with an image, name, price, description, and **Add to Cart** button
- Dynamic shopping-cart badge showing the total number of plants
- Redux Toolkit cart state with add, remove, and quantity-update reducers
- Cart page with unit prices, subtotals, total plant count, and order total
- Increase, decrease, delete, continue-shopping, and checkout controls
- Responsive layout for desktop and mobile screens

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Technology

React, Redux Toolkit, React Redux, Vite, JavaScript, and CSS.
